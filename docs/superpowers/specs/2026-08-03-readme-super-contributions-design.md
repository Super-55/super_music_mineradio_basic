# README：Super 改造与维护说明设计

## 目标

重写当前仓库的 README，使读者能够清楚看到 `Super` 在原 Mineradio 项目基础上的持续改造、问题修复、架构收敛和发行工作，同时准确保留原作者、原始设计与 GPL-3.0 授权归属。

## 公开身份

- 当前定制版维护者统一署名为 `Super`。
- 不公开真实姓名、本机用户名、邮箱、支付渠道或其它个人信息。
- 不把 `Super` 描述为 Mineradio 原始项目的从零作者。
- 明确说明当前仓库是在原 Mineradio 基础上持续改造的定制版本。

## README 结构

1. 项目标题、主视觉和一句话简介。
2. `super_mineradio_s` Windows 发行版下载区：提供 GitHub Release 页面、安装包和 SHA-256 文件链接。
3. 当前版本：应用内部版本 `2.0.2`，定制发行标签 `v1.0.0`。
4. `Super 的改造与维护`：以可核查的工程成果为主，不使用空泛宣传。
5. 当前核心能力：只描述现有架构，不保留已经移除的多平台在线搜索、播放和自动换源能力。
6. 安装和开发运行说明。
7. 第三方平台、隐私和版权说明。
8. 致谢与维护关系：保留 XxHuberrr 和 emily 的原始贡献说明，补充 `Super` 的定制版维护说明。

## Super 的成果清单

README 应覆盖以下工作：

- 把在线音乐架构收敛为酷狗概念版唯一在线音乐来源。
- 删除网易云、QQ、汽水、Spotify 的在线搜索、播放和自动换源链路。
- 保留本地音乐/MP3 导入和播客功能。
- 修复酷狗概念版登录页面、登录状态、VIP 状态和远程歌单获取链路。
- 参考酷狗概念版协议改进播放地址、会员权限和音质请求。
- 对受限歌曲、无可用地址和切歌失败增加队列跳过与防卡死处理。
- 改进无损音质请求、实际音质识别和降级提示。
- 支持酷狗原文歌词和译文，增加歌词缓存、下一首预取、原文/译文分阶段加载和播放前最多 800ms 的原文歌词门控。
- 调整首页模块比例与整体容器滚动行为。
- 修复源码启动快捷方式及 Windows 图标缓存问题。
- 建立 `super_mineradio_s.exe` 发行构建、SHA-256、发行内容脱敏审计和 GitHub Release 流程。
