# 酷狗单在线音源与歌词译文修复设计

## 目标

Mineradio 的在线音乐能力只保留酷狗概念版，删除网易云、QQ 音乐、汽水音乐和 Spotify 的歌曲搜索、歌曲播放、手动切源与自动换源能力。同时保留本地音乐/MP3 导入和播客，并让酷狗歌曲优先使用酷狗 KRC 中自带的翻译歌词。

## 范围

### 保留

- 酷狗概念版登录、会员状态、VIP 领取、搜索、推荐、歌单、收藏、歌词和全部播放能力。
- 本地歌曲、本地文件夹和 MP3 导入播放。
- 播客浏览、队列和播放能力，包括播客实现所需的专用服务端代码。
- 酷狗内部的音质选择、同源地址重试和受限歌曲跳过。

### 删除或关闭

- 网易云、QQ 音乐、汽水音乐和 Spotify 的歌曲搜索入口及对应前端调用。
- 上述平台的歌曲播放 URL 解析入口及播放器分支。
- 播放器上的可点击音源标记和手动音源切换菜单。
- 跨平台同名歌曲搜索与自动换源。
- 使用网易云搜索补齐其他平台歌词译文的回退逻辑。

### 不在本次范围

- 不删除或重写播客专用接口，即使其底层与旧音乐平台共享少量基础代码。
- 不改变本地歌曲的播放方式。
- 不改变酷狗账号、歌单、VIP 和音质协议。
- 不进行与本目标无关的界面或服务端重构。

## 架构设计

### 1. 在线音源边界

播放器把歌曲分为三类：

1. `kugou`：唯一允许的在线音乐类型。
2. `local`：本地音乐和导入文件。
3. `podcast`：播客。

任何来自 `netease`、`qq`、`qishui` 或 `spotify` 的普通音乐对象均视为旧数据，不再进入新搜索结果和播放流程。恢复历史队列时过滤这些对象；酷狗、本地和播客项目保持原顺序。

### 2. 搜索和入口

首页与搜索框只请求酷狗搜索接口。旧平台标签、搜索模式、歌曲操作入口和前端请求分支删除。服务端的旧歌曲搜索与歌曲播放路由不再作为可用能力暴露；播客专用路由继续存在。

播放器上的来源标记只展示不可交互的 `KG`、`本地` 或`播客`标识，不创建音源切换弹层，也不并行查询其他平台。

### 3. 播放失败处理

酷狗歌曲按以下顺序处理：

1. 使用请求音质和对应酷狗 Hash 请求概念版播放地址。
2. 在酷狗内部按现有质量链重试可用地址。
3. 若仍不可播，保留现有的受限提示和有界队列跳过，最多连续检查三首。

流程不得调用其他平台搜索或替换当前队列歌曲的 provider。自动跳到下一首属于队列控制，不属于跨平台换源，继续保留。

### 4. 酷狗译文

当前实现只下载 `fmt=lrc`，并固定返回空 `trans`。新流程对同一歌词候选同时获取：

- LRC：作为稳定的原文逐行歌词。
- KRC：通过固定 XOR 密钥解密并使用 Node.js `zlib` 解压。

KRC 的 `[language:<base64>]` 元数据解析为 JSON。选择翻译类型内容，将翻译行与 KRC 的时间行按索引对应，再生成标准带时间戳的 `tlyric`。接口同时返回 `trans` 和 `tlyric`，供现有前端歌词合并器使用。

异常处理：

- KRC 不存在、格式不合法或没有翻译时，仍返回原 LRC。
- 翻译行数与 KRC 时间行不一致时，只映射双方共有的有效范围，跳过空白译文。
- 不使用网易云或其他平台补译。
- 歌词持久缓存键升级版本，绕开已有的空译文缓存。

### 5. 兼容与清理

- 旧的非酷狗在线队列项目在读取时被丢弃，不转换成错误的酷狗歌曲。
- 已经在播放的本地音乐和播客不受影响。
- 删除前端手动/自动跨平台换源代码后，保留同名函数的兼容空壳仅在启动顺序确有调用依赖时使用；空壳不得发起网络请求。
- 服务端清理以歌曲搜索和播放边界为准，不误删播客依赖。

## 测试设计

### 酷狗歌词

- 使用固定 KRC 加密样本验证 XOR、zlib 解压和 `[language:]` 解析。
- 验证翻译行生成正确的 LRC 时间戳。
- 验证损坏 KRC 或无翻译 KRC 仍返回原歌词且不抛出异常。
- 验证歌词接口不再固定返回空译文。

### 单在线音源

- 搜索入口只能构造 `/api/kugou/search`。
- 来源菜单不再包含网易云、QQ、汽水或 Spotify，也不可触发切源。
- 自动播放失败处理不得调用跨平台搜索函数。
- 历史队列过滤保留酷狗、本地和播客，移除四个平台的普通歌曲。
- 旧平台歌曲搜索和歌曲播放路由不可用，播客路由仍可用。

### 回归验证

- 酷狗登录、歌单和 VIP 状态正常。
- 酷狗普通、VIP 和无损歌曲可播放。
- 本地 MP3 可以导入并播放。
- 播客可以进入队列并播放。
- 受限歌曲有界跳过逻辑保持有效。

## 完成标准

- 在线音乐搜索结果全部来自酷狗概念版。
- 播放期间不存在手动或自动切换到其他在线平台的路径。
- 具有酷狗内嵌译文的歌曲能显示译文；没有官方译文的歌曲只显示原文。
- 本地音乐和播客功能不受影响。
- 相关自动化测试、语法检查和实际运行验证通过。
